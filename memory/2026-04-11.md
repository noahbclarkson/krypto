**The pattern:** Every time we run a hyperopt and report the winning Sharpe, we're reporting in-sample performance against that specific walk-forward split. True OOS requires a held-out validation set that the hyperopt never touched.

**Third biggest blind spot: We keep tweaking the same 3 strategies.** Turtle+Chandelier, A/D Momentum, DDBudget 3-sleeve. These are all directional trend-following at daily resolution. We've tested and rejected: FDUSD basis carry, funding MR, cross-sectional momentum, BOCPD regime, 4h MR, lead-lag pair trades. The well of non-trend alpha is dry. We should either accept this and focus on improving the trend-following infrastructure (W05 protection, vol-contingent hold) or go to a completely different timeframe (intraday microstructure).
