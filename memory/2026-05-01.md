## PART 6: UPDATES TO STRATEGY-IDEA FILES

### Update strategy-ideas.md with new concept:

**Concept: Regime-Adaptive Exit (RAE) — Different Exit Mechanism for Different Regimes**

Current architecture: Turtle ATR exit + Chandelier exit run in parallel (OR logic — first one fires). Problem: both exits use fixed periods (ATR P=24, Chandelier P=7). Neither adapts to the current volatility regime.

Hypothesis: In high-vol regimes, tighten the Chandelier multiplier (not period). In low-vol regimes, loosen it. The period controls timing (how many bars for thetrailing stop to catch up to price), the multiplier controls sensitivity. Period=7 means Chandelier needs ~7 days of upward momentum to establish a meaningful high-water mark. In a 3-day trend, P=7 never fires tight. But M=2.30 is the same in all regimes.

**Test:** Sweep CHAND_MULT ∈ {1.50, 1.75, 2.00, 2.30, 2.75, 3.00} with regime-conditional multiplier: high-vol → M×1.1 (looser), low-vol → M×0.9 (tighter). Compare to fixed M=2.30 baseline.

**Why different from prior vol-contingent Chandelier (GRAVEYARD):** Prior attempt was a multiplier on the stop (same period, different distance). That produced identical results across configs. This would vary the multiplier by vol regime — mechanistically different.
