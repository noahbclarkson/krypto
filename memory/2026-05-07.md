Base5 is BTC/ETH/SOL/XRP/DOGE/ADA — 6 pairs we specifically selected because they trend. T80 confirmed: UNI fails 5/6, AVAX borderline 4/6. ### 2. We have not shipped anything live
After 3 months of v2-rewrite and ~50 example files committed, nothing has touched real or testnet capital. The entire project is a simulation. Every metric is an upper bound. We cannot know if the live execution path (order creation, exchange API interactions, position accounting, hedge logic) even works until it runs against an exchange.

**The opportunity cost:** We have spent the last 3 sessions (each 4h = 12 human-hours) confirming the same harness gap pattern. T84 could have been the last hyperopt session before shifting entirely to deployment infrastructure. Instead, we re-confirmed a known failure mode without building a new capability.

### 3. Fee model uncertainty is the biggest unmeasured variable
