## [22:07 UTC] Session: Turtle+Chandelier 9-University Walk-Forward (Finally Built & Validated)

### Context
Previous sessions flagged Turtle+Chandelier (71.4% pass, avg Sharpe +2.36) as the most robust single-strategy result — but this was from the regime-conditional harness using BTC-only signals. No dedicated multi-symbol walk-forward existed.

### What was done
Built `examples/turtle_chandelier_walkforward.rs` from scratch:
- Turtle breakout entry (EP=21) with Chandelier(45, 2.5) exit
- 9 universes × 6 walk-forward windows (252/252 train/test)
- Dollar-volume-ranked top-2 symbols per bar
- 0.1% taker fees each side

### Critical bug found and fixed
Initial version produced 0 trades across all 54 windows. Root cause: Donchian high computation included the CURRENT bar's high in the lookback, making breakout mathematically impossible (close can never exceed a high that includes its own bar). Fixed by excluding current bar: `start..idx` instead of `start..=idx`.

### Honest assessment
- **59% pass rate is below the 70% threshold.** Turtle+Chandelier is NOT a standalone HOF strategy at this confidence level.
- The previous 71.4% was an artifact of BTC-only single-symbol testing. Multi-symbol testing is harsher.
- 476 trades across 54 windows = ~8.8 trades/window — statistically meaningful.
- No regime filter was applied (unlike the SMA200 filter that killed all signals). Pure Turtle breakout.
- Positive average return across ALL 9 universes (even the ones that failed pass rate).

### Conclusion
Turtle+Chandelier is a viable strategy component but NOT a standalone leader. It works best in concentrated universes (Base5, LowVolume5) and struggles in legacy baskets. It should be treated as one sleeve in a multi-strategy book, not a standalone alpha source.

### SMA200 regime filter observation
Adding a simple SMA200 regime filter (only long when close > SMA200) killed ALL signals across all 54 windows. This suggests Turtle breakouts in crypto often happen during transitional periods (recovering from dips) when price is below its 200d SMA. The regime filter removes the exact entries that make Turtle work. This is an important negative result.

### Corrected results (close > max_close instead of close > max_high)
After matching the signal definition to the regime_conditional harness (close > max_close of previous N bars, not close > max_high):

**GLOBAL: 37/54 pass (69%), avg Sharpe 3.26, 538 trades**

This is much closer to the original 71.4% estimate (which was BTC-only). The 69% multi-symbol pass rate confirms Turtle+Chandelier is a credible strategy — just barely below the 70% threshold. Legacy3 (BTC, XRP, LTC, EOS) passes 83%.

Key lesson: signal definition matters enormously. `close > max_close` is a weaker breakout signal than `close > max_high`, producing more entries and higher pass rates but potentially worse per-trade quality.
