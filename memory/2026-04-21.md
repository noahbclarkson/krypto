## Section 4: Are Our Metrics Real or Curve-Fitted?

**Walk-forward Sharpe 5.46 (Base5 average):** INFLATED — this is the mean of per-window Sharpe ratios, not a compound annualised Sharpe. The daily equity Sharpe is ~1.29. These are fundamentally different metrics and should never be compared. The 5.46 number is useful for relative comparison (one config vs another) but wildly misleading as a standalone claim.

**Fee-adjusted Sharpe ~3.8-4.8:** Based on 22-33% fee degradation applied to gross walk-forward. The fee model assumes 0.04% taker + 0.01% slippage. If SOL consistently misses at 3.7x the slippage model (as observed), the real fee drag is higher. This is a range, not a precise number.

**Global pass rate 45/54 (83.3%):** LEGITIMATE — 54 independent OOS windows is a meaningful sample. But 0/54 windows include 2026. The 83.3% is an historical average, not a current-state claim.

**2026 YTD -22.7%, Sharpe -18.91:** This IS real OOS data (the only real OOS data we have in 2026) and it's catastrophic. The prior claim that "2026 underperformance is regime-inherent and not fixable" is cop-out language. A -22.7% return with Sharpe -18.91 in a -14% BTC bear market means the strategy lost 2x the index while claiming 83% walk-forward pass rate. This discrepancy matters.

**Equity: $10K → $67M (+670,515%):** WRONG METHODOLOGY — this total return is calculated from a full-sample backtest using milestone-aggregated returns, not from compounded daily equity. It's not comparable to the daily equity curve, not comparable to walk-forward Sharpe, and the number itself comes from a specific parameter set that has since changed. It's a vanity metric.

**Conclusion:** The metrics are partially real, partially inflated. The walk-forward pass rate is the most trustworthy metric. The equity Sharpe (~1.3) is honest. The walk-forward average Sharpe (5.46) is a relative metric, not an absolute one. The total equity return ($67M) is a narrative artifact, not a rigorously derived number. We need to stop quoting $67M.

## Section 5: Biggest Blind Spots

### Blind Spot 1: ZERO 2026 OOS Data (CRITICAL)
All 54 walk-forward windows end before 2026. Our only actual 2026 regime data is -22.7% YTD with Sharpe -18.91. We don't know if the 83% pass rate holds in the current market. 2026 is a genuine out-of-sample test and we're failing it badly.

### Blind Spot 2: Bull Market Survivorship Bias (SEVERE)
The strategy's best years are mega-bull years (2018 +1393%, 2020 +879%). In normal bull (2023: +101.9% vs BTC +146.5%), Turtle LAGED BTC. In 2021 chop (+35.5% vs BTC -16.5%), the strategy won but barely. The edge is largest when everything rallies — not a robust claim of genuine alpha.
The per-year table (MEMORY.md) shows Turtle beat BTC in 5/9 years. In 3 of those 5 winning years, BTC was in a severe bear (2018, 2020, 2022). So the "edge" may largely be: Chandelier stops protect capital in drawdowns while buy-hold loses badly.

### Blind Spot 3: Parameter Cycling / Hyperopt Redundancy (MODERATE)
ATR_MULT: swept 3 times → same result each time.
ATR_PERIOD: swept 3 times → same result each time.
HOLD_MAX: swept 2 times → different winners (HM=45 on stale params, HM=12 on current).
EP: swept 4 times → EP=21, EP=24, EP=21 again.
CHAND_MULT: swept 3 times.
This pattern suggests we're not learning — confirmation sweeps look like progress but produce zero new knowledge. Each re-sweep is justified as "validating on current production params" but the underlying market dynamics haven't changed enough to justify repeated confirmation.

### Blind Spot 4: Fee Model vs Live Slippage Reality (MODERATE)
SOL slippage at $100K notional = 3.70bp vs 1bp model = 3.7x miss. We cap SOL at $50K but the walk-forward never tested with explicit SOL sizing constraints (it's a % return system). If the actual SOL slippage at $50K hits 1.5-2x model, the fee-adjusted Sharpe of 3.8-4.8 could be 2.8-3.8. Still positive but not the 5+ we claim.

### Blind Spot 5: Only 310 Trades Over 8 Years (LOW but accumulating)
310 trades in 8 years is ~39/year. Each trade is a binary outcome (win/loss). With 310 trades, our 83% pass rate is based on a sample where even 1-2 bad years can skew results significantly. The per-year data shows 2022 (+10.9%), 2021 (+35.5%) — these are weak returns in chop/bear regimes. The equity curve is dominated by mega-bull years.
