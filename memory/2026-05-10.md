### 3. 2026 YTD Underperformance (-22.7% vs BTC +12.7%) Is Unresolved

PLAN.md documents this every session and does nothing about it. The ATR_RANK gate skips entries in chop/divergence regimes but does NOT reduce position size. It is a binary filter, not a continuous risk dial. The regime classifier does not adjust exposure — it just decides yes/no on entries.

This means in a sideways/bear regime, the strategy:
- Skips some entries (fewer signal fires)
- But holds full size on the entries it does take
- Takes more whipsaw losses when BTC divergence/chop is occurring

The problem is not that we're in a bad regime. The problem is that the regime response is discontinuous (binary skip vs full size) rather than graduated.

### 3. Regime-Scaled Position Sizing (PRIORITY: LOW — NEW CONCEPT)
**Concept:** Replace the binary ATR_RANK gate (skip if T<5, else full size) with a graduated position size:
- If ATR_RANK < 2 (very low vol, chop): position size × 0.5
- If ATR_RANK 2–5 (medium vol): position size × 0.75
- If ATR_RANK > 5 (high vol, trending): full size × 1.0

**Why it could work:** Addresses the 2026 YTD problem — when BTC is diverging/choppy, the strategy takes full-size positions on filtered entries and gets whipsawed. Reducing size in low-vol regimes reduces drawdown without sacrificing the big trending winners.

**Why it's hard:** The current ATR_RANK T=5 gate is binary. The vol-scaled version adds a continuous risk management layer. Need to validate that graduated sizing doesn't reduce returns more than it reduces drawdown. Also: top-10 concentration means sizing down in any regime risks missing the big winners that are often in lower-vol regimes (SOL 2023-01-11 was low-vol at entry).

**Status:** Concept only. Requires T73-style top-winner preservation audit before testing.

## Biggest Blind Spots

1. **We only test in historical backtests.** All equity numbers are simulation upper bounds. We don't know if the fee model, slippage, or position sizing work in real markets. We won't know until live execution.

2. **We are implicitly only validated in bull/hot crypto markets.** The Base5 universe (BTC/ETH/SOL/XRP/DOGE/ADA) are selected because they trend well. UNI fails 5/6. AVAX fails 2/6. The strategy is optimized for high-beta trending crypto — not general crypto. This is survivorship bias in the universe selection.

3. **We over-trade relative to what the convex tail requires.** With 91% of return in top-10 trades, we should be trading fewer, larger positions — not more frequent smaller ones. But we have no mechanism to size positions by conviction.

4. **We keep documenting problems instead of fixing them.** The ATR_RANK binary gate problem has been in PLAN.md for 3 weeks. We describe it, we note the impact, and we don't fix it or decide it's unfixable. "Documented but unsolved" is a cop-out after 3+ weeks.
