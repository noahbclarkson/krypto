## Step 1: Parameter Audit

**Chosen parameter:** MACD slow period (EMA lookback for MACD signal line)

**Why this parameter:**
- Hardcoded assumption: `slow=26` (classic Gerald Appel 1980s default)
- Previously sweep showed fast=12 slow=25 beats fast=14 slow=30 — but that was a BOUNDED sweep (15-100 with step 5)
- Classic value (26) was never tested against the FULL integer range
- This is a **core strategy parameter** used by MACD+Regime, Turtle+MACD, head-to-head benchmark

**Not audited (already validated/frozen):**
- Turtle params: all frozen (EP=21, ATR=25, ATR_mult=0.0, CHAND P=28/M=2.0, HM=45, CAP=3, HOLD_MAX=54)

### Key finding

The "sweet spot" for MACD slow period is in the **65-69 range** — not the classic 26. This is a significant shift: 2.5× the classic lookback.

The improvement is modest in Sharpe (+6.5%) but consistent. Baseline slow=26 has higher worst DD (84.3% vs 73.9-74.7% for slow=65-69), which makes the optimized values more attractive on a risk-adjusted basis.

**Equity curve results (Base5, all windows compounded):**
- slow=26 (baseline): final=2.53×, max DD=92.8%
- slow=65 (winner): final=20.02×, max DD=97.8%
- slow=66 (runner-up): final=16.92×, max DD=97.8%

Wait — these equity figures show slow=65/66 crushing slow=26. But the avg return column says slow=65 is +98.4% vs slow=26 at +92.3%. The equity curve final values are much more dramatic. This discrepancy requires investigation: the equity curve compounds across all windows while the avg return column averages per-window returns. A few outlier windows where slow=65/66 performs extremely well would explain both.

## Step 4: Updated Defaults

**No code change recommended.** Here's why:

1. The strategy being tested (plain MACD with fixed 21-bar hold) is NOT the production strategy. Turtle+Chandelier is production.

2. MACD as a signal component would update `src/features/indicators.rs` (slow EMA). The current value there is fast=28, slow=26 per `hyperopt-2026-04-08` (which found fast=28 was the winner over fast=12). So the codebase already uses slow=26 for MACD — but via the fast EMA override path.

3. The improvement is modest (+6.5% avg return) and the equity curves show dramatically different behavior (20× vs 2.5×). This needs verification before committing.

4. **Recommendation:** Keep researching MACD slow period, but the production strategy (Turtle+Chandelier) is unaffected. Mark this as a candidate for future MACD-based strategies but do not update indicators.rs yet.
