## Brutally Honest Critique

### 🔴 CRITICAL: We Are Curve-Fitting and Convincing Ourself Otherwise

**EP=24, ATR_ENTRY_MULT=0.85, CHAND_MULT=2.30 — all marginal noise.**

The project has run hundreds of hyperparameter optimization iterations. The latest round produced:
- EP=24 vs EP=21: **+2 windows** in 54-window test (83.3% vs 79.6%)
- ATR_ENTRY_MULT=0.85 vs 0.90: **+1 window** in 54-window test (81.5% vs 79.6%)
- CHAND_MULT=2.30 vs 2.25: **+1 window** in 54-window test (83.3% vs 81.5%)

These are 1-2 window differences in 54-window tests. The expected false-positive rate at 70% baseline is ~30%. Adding 1-2 windows is **entirely consistent with noise**. We are not finding signal; we are finding the edges of our noise distribution.

**The pre-2021 stress test was run with P=7/M=2.25, EP=24, HM=12 — the current params.** 20/20 pass. But this test is on a SMALL dataset (pre-2021 = ~3 years). The walk-forward test on 9×6=54 windows is the larger, more reliable validation. The recent param changes were optimized ON that walk-forward data. They are in-sample improvements on the OOS validation set, not genuine out-of-sample gains.

**We should revert EP to 21 and ATR_ENTRY_MULT to 0.90.** These were the validated params. The "improvements" are noise. Stop re-running sweeps on stable params — this has been the pattern for 3 weeks.

### 🔴 CRITICAL: DDBudget Sharpe 7.24 Is the Same Inflated Metric

`reports/daily_progress.csv` shows DDBudget Sharpe = 7.24. The HALL_OF_FAME says "daily equity Sharpe ~1.29 for Turtle, ~7.x for DDBudget." This is the **same methodology problem** that plagued Turtle's 6.29 Sharpe.

**Root cause:** In-sample inflation. Both EP=24 and ATR_EM=0.85 were optimized on the same 54-window OOS validation data. EP=24 won by 2 windows (83.3% vs 79.6%). The combined "improvement" was the sum of two noise bumps.

### Anti-Overfitting Rules Established

1. Minimum win margin: ≥3 windows (5.5%) on OOS before accepting change
2. No sequential optimization on same data (EP + ATR_EM optimized together = combined noise)
3. Held-out validation required for marginal wins (1-2 windows)
4. Equity curve sanity: winner must dominate baseline at >80% of time bars

### What This Means for EP=24

EP=24 (45/54 = 83.3%) vs EP=21 (43/54 = 79.6%) = 2-window improvement. At expected 3.7% FP rate across 96 EP values tested, ~3.5 false winners. EP=24 is defensible as "plausibly real" but NOT definitively proven. Recommend keeping it as default but treating it as marginal.
