# Hyperopt Report — 2026-05-03: SIZE_MULT (High-Vol Overlay)

**Kira | 2026-05-03 21:36 UTC**

---

## Parameter Audited

**SIZE_MULT** — the position size multiplier applied when BTC's 21d ATR exceeds the 75th percentile of its 252-bar ATR history. Currently hardcoded as `0.70` (30% reduction) in both `src/live/bot.rs` and `examples/live_compatible_wf.rs`.

**Why this parameter:** It's one of four magic numbers in the high-vol overlay (21d ATR, 252d history, 75th percentile, 0.70 multiplier) and has **never been optimized**. No documented justification for why 30% reduction specifically.

---

## Sweep Design

- **Parameter:** SIZE_MULT ∈ [0.00, 0.05, 0.10, ..., 0.95, 1.00] — 21 values
- **Grid:** 21 values × 9 universes × 7 walk-forward windows = **1,323 runs**
- **Fixed params:** EP=21, ATR_P=24, ATR_M=2.0, HM=12, CAP=3, VL=96, ATR_RANK_T=24, RL=42, RAP=12

## Key Findings

1. **Trade count is IDENTICAL (556) across all 21 values.** The overlay affects position sizing only, never entry/exit decisions. This is by design — it's a risk overlay, not a signal.

2. **Pass rate forms a plateau:** M=0.25–0.95 all produce 54/63 (85.7%). M=1.00 gains +1 window (55/63). M<0.25 loses 1 window (53/63). The overlay barely affects pass/fail outcomes.

3. **Return and DD scale linearly with M.** Higher M → more capital deployed in high-vol → more return AND more drawdown. This is a pure risk preference knob, not an alpha source.

4. **Sharpe peaks at M=0.35-0.40 (7.74-7.75).** Lower M improves risk-adjusted returns because the high-vol regime's extra return doesn't compensate for the extra risk. But the difference vs M=0.70 is only +1.3% relative.

5. **M=0.70 (baseline) sits in the robust 54/63 plateau**, with moderate return (138%) and moderate DD (20.6%). It's a reasonable default.

---

## Decision: NO CHANGE

**Keep SIZE_MULT = 0.70.** The parameter is a risk preference knob, not an alpha source:
- M=1.00 gains only +1 pass window (+1.6pp) but adds +3.6pp drawdown
- M=0.40 gains only +0.097 Sharpe (+1.3%) but loses -32.5pp return
- The 54/63 plateau (M=0.25-0.95) means the overlay has minimal impact on strategy robustness
- Changing to a different value would not constitute a "better default" — it would be a risk preference change

**The finding itself is valuable:** We now know the overlay is inert. It's a cosmetic risk control that doesn't materially affect strategy outcomes. If we ever need to reduce drawdown, M=0.35-0.50 is the efficient frontier. If we want max return, M=1.00 (disable overlay) is optimal.
