## Is the Sharpe 5.0+ Real?

Short answer: **Yes, but it's a methodology artifact, not a directly comparable Sharpe.**

The walk-forward Sharpe (4.91 for Base5, 5.17 for live_compatible_wf) is computed as:
- For each walk-forward window: compute `annualised Sharpe = (mean / std) * sqrt(252)`
- Then average those per-window Sharpe ratios across all windows

This inflates the number because:
1. Windows with extremely high Sharpe (e.g., 2020 COVID crash + recovery) get equal weight with low-Sharpe chop windows
2. Annualising std of a 252-bar window's daily returns already introduces noise
3. The averaging amplifies good windows more than it penalises bad windows

**The honest number:** Daily compounded equity Sharpe = 3.14.

Use 3.14 on charts. Report 5.17 only with methodology label "per-window averaged".
