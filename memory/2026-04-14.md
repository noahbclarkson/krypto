The daily equity harness (and walk-forward harness) both enter at `sd.close[bar]` — the same bar the signal fires on. This is slightly optimistic: real Turtle enters at next bar open. Both harnesses have this consistently, so relative comparisons are valid. The walk-forward Sharpe (6.29) is the production-valid metric; the equity curve is for visualization only.

In 2023, Turtle returned only +10.9% vs BTC +28.6%. In choppy ETF-approval bull markets, Turtle gets whipsawed by false breakouts. Full Kelly position sizing (used in daily equity) amplifies this drag. The walk-forward harness uses fixed $10K notional per position — different risk profile. Production strategy (walk-forward validated) does NOT use full Kelly.
