## Decision Logic

**Winner by pass rate:** P=10 (77.8%, +4.4pp vs baseline) ✓
**Winner by Sharpe:** P=5 (38.665, +16.6% vs baseline) ✓

**Anti-overfitting checks:**
- P=10: Δpass=+4.4pp (✓), ΔSharpe=-1.64% (✓ < 5% threshold)
- P=5: Δpass=+2.2pp (✓), ΔSharpe=+16.6% (✓)
- Both pass anti-overfitting criteria individually

**BUT:**
- No single value dominates both criteria simultaneously
- P=5's Sharpe advantage is concentrated in a few outlier windows (noise)
- P=10's pass rate advantage is consistent but Sharpe is WORSE than baseline
- P=7 (baseline) is already validated on held-out pre-2021 data (67.9% pass)
- The "winner" depends on which criterion you prioritize (pass rate → P=10, Sharpe → P=5)
- Picking either would be chasing a metric rather than finding robustness

**VERDICT: NO CHANGE. CHAND_PERIOD=7 stays as validated production default.**
