## Target: Turtle ATR Exit Period

### Prior State

The Turtle system has TWO distinct ATR-based exits that are often conflated:
1. **Chandelier ATR(28, 2.0)** — validated 2026-04-11 as optimal period at M=2.0
2. **Turtle ATR(N, 2.0)** — the ORIGINAL Turtle system exit, N=20 by convention, **NEVER VALIDATED**

The `turtle_chandelier_walkforward.rs` was using ONLY Chandelier ATR(28) as the exit. The original Turtle system's native ATR(20) exit was never tested.

### Design

**Strategy:** Turtle breakout + Chandelier(28,2.0) OR Turtle_ATR(N,2.0) — exit fires on whichever triggers first.

**Sweep:** ATR_PERIODS ∈ {10, 15, 20, 25, 28, 30, 35, 40, 50, 60} (10 values)
**Mode:** DUAL_EXIT (Chandelier OR Turtle fires first) + CHAND_ONLY baseline
**Validation:** Walk-forward 252 train / 252 test, 9 harsh universes, ~6 windows each

### Key Findings

1. **ATR=25 DUAL_EXIT is the winner.** Best global Sharpe (6.287), best pass rate (50/54), lowest worst DD among top performers (70.3%).

2. **DUAL_EXIT mode improves pass rate from 91% → 93%.** One additional window (Legacy5BNB W04) now passes.

3. **Sharpe improvement: +3.6%** (6.070 → 6.287) — modest but consistent across universes.

4. **Worst DD improvement: 1pp** (71.3% → 70.3%) — modest but real.

5. **Runner-ups (ATR=15, ATR=20) are within noise.** The 0.2 Sharpe difference between #1 and #5 is marginal.

6. **All configurations fail LowVolume5 W04/W05.** Structural weakness in low-liquidity assets, not parameter-tunable.

7. **ATR≥50 degrades pass rate.** Longer ATR periods (50, 60) produce wider stops that don't protect against bear regimes.

### Meta-Lesson

**The Turtle system's native ATR exit was never tested separately from Chandelier.** The original Turtle uses ATR(20) as its primary exit; we assumed Chandelier(28) subsumed this. The sweep reveals that a SEPARATE Turtle ATR(25) exit operating in parallel with Chandelier provides genuine marginal improvement — not just parameter tuning, but a second exit mechanism that catches different market dynamics.
