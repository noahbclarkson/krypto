## Critical Finding: HM=35-180 is a Flat Plateau

**HM=35 through HM=180 produce IDENTICAL results** (Sharpe 3.526, 43/54 pass, 79.6%).
This is because Chandelier(P=15, M=1.50) always fires first — the exit happens at
approximately bar 14-15. Any HOLD_MAX above ~30 is never reached.

**Decision: Keep HM=45 as production default.** HM=45 is in the safe plateau zone.
Changing it to any value 35-180 makes no difference. The parameter only matters
below ~30 bars.

---

## HM=15: Sharpe Winner (+4.4%) but Lower Pass Rate

**Winner:** HM=15 with Sharpe 3.682 (+4.4% vs HM=45 plateau at 3.526)

**Trade-off:**
- Sharpe: +4.4% improvement over HM=45
- Pass rate: 77.8% vs 79.6% (-1.8pp)
- Drawdown: 28.4% vs 28.0% (+0.4pp worse)

**Why HM=15 is better on Sharpe:** Lower HM forces faster exits in losing trades,
cutting drawdowns faster. This improves risk-adjusted returns.

**Why HM=15 fails more:** In choppy windows, the tighter forced-exit fires more often
on false breakouts that would have recovered. HM=45 lets Chandelier be the sole exit
arbiter. The 1.8pp pass rate difference comes from specific chop-heavy windows
(LowVolume5, Legacy3) where the forced exit hurts.

**Verdict:** HM=15 is a legitimate higher-Sharpe alternative for the production universe
(Base5/NoDOGE/LargeCaps5) which shows:
- Base5: HM=15 Sharpe 6.532 vs HM=45 Sharpe 5.871 (+11.3%)
- NoDOGE: HM=15 Sharpe 7.424 vs HM=45 Sharpe 6.725 (+10.4%)
- LargeCaps5: HM=15 Sharpe 7.186 vs HM=45 Sharpe 6.541 (+9.9%)

**HM=15 is the better choice for the production universe specifically.**

## Decision & Recommendation

**Production default: HOLD_MAX = 45** (unchanged, safe plateau)

**Optional upgrade for higher Sharpe:** Consider HM=15 for the production
universe (Base5/NoDOGE/LargeCaps5) — it gives +10-11% Sharpe improvement in
the universes that matter, with only a 1-window failure risk in Base5.

**Practical meaning of the plateau:** The Chandelier(P=15, M=1.50) exit is so tight
that it fires within ~14-15 bars. Any HOLD_MAX above ~30 is never reached.
The only thing that matters is: does the Chandelier stop work? (Yes — it's validated.)
HOLD_MAX is a secondary safety parameter, not a primary driver.
