## Anti-Overfit Pattern Identified

1. REGIME_LOOKBACK=42 (first optimization) → confirmed
2. REGIME_ATR_PERIOD=12 (second optimization) → confirmed
3. REGIME_ATR_PERIOD=63 (third optimization on same harness) → REJECTED

Same pattern as EP=24: 3rd sequential optimization wins marginal pass-rate improvement (+1 window) but fails held-out on Sharpe/return. The pass-rate metric in the sweep is a fragile selection criterion when the margin is 1 window.
