**Dense sweep:** 51 thresholds (t ∈ [0.0..0.0025] step 0.00005) × 9 universes × 10 WF windows = 4,590 runs

**Results:**
```
Baseline (no gate): 67/90 pass (74.4%), Sharpe 1.621, Base5 142.39x
t=0.00080 (best):   67/90 pass (74.4%), Sharpe 1.835, Base5 160.22x
t=0.00010 (aggr):   59/90 pass (65.6%), Sharpe 0.790, Base5  22.46x
t≥0.00145:          identical to baseline (0 entries blocked)
```

**Why GRAVEYARD:**
1. Pass rate NEVER improves at ANY threshold (always ≤67/90)
2. Best equity improvement +12.5% at t=0.0008 — but from blocking only 274/2849 entries (9.6%)
3. Marginal Sharpe improvement (+13%) is likely noise from handful of lucky blocks
4. Aggressive thresholds (t<0.0005) destroy performance — trade starvation
5. No held-out validation — and ATR_RANK showed how fragile such improvements are

**Meta-lesson:** Funding rate doesn't align with Turtle breakout quality. High funding (overleveraged market) doesn't reliably predict bad breakout entries. The mechanism is intuitively appealing but empirically null.
