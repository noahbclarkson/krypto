**Context:** Session 04-06 promoted `AD_PERIOD=30` to the benchmark based exclusively on a Base5-only hyperparameter sweep. I built `ad_period_9way_comparison.rs` to run period=3 vs period=30 across the standard 9-universe chronological test (252 train/test, 21-bar non-overlapping hold).

**Results:**

  - `Base5`: period=3 (+884.8%) beats period=30 (+646.6%)
  - `NoDOGE`: period=3 (+522.6%) beats period=30 (+452.9%)
  - `LargeCaps5`: period=3 (+744.1%) beats period=30 (+653.3%)
  - `Legacy5BNB`: period=3 (+190.1%) beats period=30 (+143.7%)

- **Action:** The project needs to revert `AD_PERIOD=30` back to a fast, responsive proxy (`period=3`), which better captures explosive altcoin momentum rather than acting as a smoothed, sluggish trend filter.

### 2. DOGE Universal Decomposition
**Context:** DOGE's massive +5013% nominal performance in prior sweeps led to the hypothesis that DOGE is a single-asset driver of the entire A/D strategy. I built `doge_decomposition.rs` to run the identical non-overlapping walk-forward A/D logic and track the isolated return of each Base5 component.

**Results (Isolated, fully compounded returns without leverage):**
- BTCUSDT: +630.7% (57 trades)
- ETHUSDT: +31.1% (59 trades)
- SOLUSDT: +318.4% (39 trades)
- XRPUSDT: -59.9% (57 trades)
- **DOGEUSDT: +102.1% (33 trades)**
- ADAUSDT: +269.0% (48 trades)

**Insight:**
The hypothesis that DOGE is the *only* engine of the strategy is **false**. Under strict non-overlapping walk-forward execution, BTC and SOL are actually the primary return drivers of the A/D Momentum strategy. 

*Why did previous scripts show DOGE at +5000%?* Because overlapping execution (entering a new trade every day the signal is true instead of waiting 21 bars) allows a massive price spike to compound upon itself 21 times in a single month. This confirms that the underlying edge is distributed across the market, but overlapping execution creates compounding illusions on highly volatile assets.
