**Root problem:** Two fundamentally different execution engines producing different equity curves:

### PROBLEM 2 — The Sharpe Inflation Gap is Unacceptable

| Source | Sharpe | What It Actually Measures |
|--------|--------|--------------------------|
| Walk-forward (per-window averaged) | 6.73 gross / 5.25 fee-adj | Mean of per-window Sharpe ratios — inflates by selecting best windows |
| Daily equity Sharpe | 1.04 | Actual compounded equity curve daily returns |
| **GAP** | **5.2 Sharpe points** | **~500% inflation in the reported number** |

The 6.73 is the mean of per-window Sharpe ratios. Windows with extreme returns (W03 mega-bull: +508%) massively inflate this number. W03 alone inflates avg Sharpe by ~+3 points.

**The honest number for what the strategy would actually deliver live is 1.04 Sharpe.** This is a GOOD result for crypto (crypto's own Sharpe is ~0.8-1.2) but nowhere near 5.25.

**We have been reporting the inflated number to ourselves (and to Noah) for months.** This is not fraud — it's methodology — but it creates dangerous expectations.
