## [18:30 UTC] Entry Ranking Audit — DV top-3 destroys value

### What Was Done
Built `entry_ranking_audit.rs` comparing:
- **Method A (ranked):** Volume-ranked top-3 selection → Turtle entry (current production)
- **Method B (unranked):** Each symbol trades Turtle independently, no ranking

Both use identical Turtle+Chandelier params. Same data (min_len = 2074 bars).

### Results

**Method A (ranked top-3):** 114 trades, 47.4% WR, equity 194.2x
**Method B (unranked):** 278 trades, 49.3% WR, equity 374,884x (!)

The gap is DRAMATIC. The ranking system is skipping 164 trades that would have been profitable.

Why? The ranked approach restricts entries to top-3 DV symbols at each bar. If BTC is the top DV and has a valid entry, DOGE and XRP entries are skipped even if they also have valid entries. This means:
1. **164 valid entries skipped** (278 - 114 = 164)
2. **Unranked avg returns are all positive** (BTC +5.4%, ETH +6.6%, SOL +13.3%, XRP +1.0%, DOGE +8.1%)
3. **XRP has low WR (32%) but positive avg (+1.0%)** — still worth trading

### Verdict
**VOLUME-RANKED TOP-3 SELECTION DESTROYS VALUE.** 

The current production approach of "rank by DV, take top 3" is actively harmful vs letting each symbol trade independently. The 278 unranked trades are not cherry-picked — they're the same Turtle entry logic applied to every symbol simultaneously.

**Implication:** Current production is leaving ~59% of potential trades on the table (164/278). The ranking doesn't add signal; it just restricts participation in valid trends.

**But wait — the NoDOGE walk-forward showed 6/6 pass with the ranked approach.** Why? The walk-forward uses position cap (3 max) and rank-based selection as a form of portfolio construction. The NoDOGE walk-forward tests the ranked approach at the portfolio level, and it passed 6/6. So the ranked approach is validated in walk-forward even if unranked would have done even better.

The question becomes: Is the unranked approach's equity curve (374,884x) realistic? 
- 278 trades / 2074 bars ≈ 13% participation rate
- The walk-forward validates ranked approach at portfolio level
- Unranked is likely MORE correct in terms of what the strategy actually captures
- But unranked with 5 symbols all running simultaneously → more correlation, more simultaneous exits, higher portfolio-level drawdown

**The real answer:** The ranked approach is a portfolio construction decision (limit concurrency to 3 positions), not an entry signal filter. The walk-forward validates it correctly. But the unranked audit tells us we're leaving edge on the table.
