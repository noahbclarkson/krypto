- **2022**: Sharpe 0.51 — BTC bear (-45.6%), Turtle +10.9% (missed much of the crash upside)
- **2026 YTD**: Sharpe -5.31 — Turtle -22.7% vs BTC +12.7% (early 2026 underperformance)

### Finding 2: Sharpe Numbers Are Not Directly Comparable

Three different Sharpe figures exist for Turtle+Chandelier:
1. **Walk-forward per-window Sharpe: 6.29** — mean of per-window Sharpe ratios, computed as `mean/std * sqrt(252)` per window then averaged. NOT a daily compounded Sharpe.
2. **Daily equity Sharpe: ~1.0-1.3** — computed from actual daily returns on the equity curve. **This is the honest number for the equity chart.**
3. **Progress chart (old, WRONG): 2.80** — from fixed 21-bar hold execution engine (wrong mechanism).

**Never report 6.29 as "the Sharpe" on an equity chart.** The daily equity Sharpe (~1.0) and the walk-forward window Sharpe (6.29) are different statistical objects.

### Finding 3: Execution Engine Architecture Problem (Still Unfixed)
The `progress_equity_curves.rs` (1167 lines) uses fixed 21-bar hold for ALL strategies including Turtle. The corrected `turtle_chandelier_equity.csv` uses Chandelier dual-exit.

These are fundamentally different execution engines producing DIFFERENT equity curves:
- Fixed hold, day 1999 (2023-07-30): **248x** 
- Chandelier dual-exit, same date: **1786x**

**Do NOT compare or blend equities from different execution engines.**

The fix exists: generate a separate `turtle_comprehensive.png` (done) and optionally rebuild `progress_equity_curves.rs` to use Chandelier for Turtle (not done — 1167 lines).
