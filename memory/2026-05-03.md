EP=24 failed held-out validation. ATR_RANK=24 has never been held-out validated. The 54/63 pass rate is in-sample OOS performance — the most dangerous kind. We should run T42 (held-out validation) before citing this as truth.

**2. Config drift between harness and live bot**
live_compatible_wf.rs hardcodes VL=96 while src/live/config.rs has VL=8. Which is actually running in production? The validated harness shows VL=96 but the deployed bot uses VL=8. This 12x difference in volume smoothing could materially affect symbol selection.

**3. No sustained bear market test**
Walk-forward windows cover 2020-2026: the largest BTC bull market in history. The 2018-2019 bear (-83%, 12+ months) is NOT in any OOS window. Our Sharpe 1.04 and 110x equity are bull-market numbers. In a grinding prolonged bear, the equity curve could look very different.

**4. Still no short-side sleeve**
Every strategy in the book is 100% long. We proposed a short-side sleeve on 2026-04-05 and never touched it. We can express bearish views only by reducing exposure, not by shorting. This is a structural gap.

**5. LOB NOBI, BTC-ETH pairs, ETF flow — all proposed, none built**
We are generating ideas at 10x the rate we test them. This is the core problem. The three ideas above have been documented since 2026-04-06/07 — nearly a month. They remain proposals.

**6. Fee model is inconsistent across strategies**
A/D (40.3x, 3933 trades) may have different fee treatment than Turtle (0.98 Sharpe, 397 trades). The A/D number looks 10x better but it may be running with optimistic fee assumptions or intraday bars.
