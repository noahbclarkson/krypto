### HIGH 3: The Walk-Forward Sharpe 5.46 Is Not What It Appears

Walk-forward Sharpe is the mean of per-window Sharpe ratios. Each window's Sharpe = (mean daily return × √252) / std. This methodology:
- **Inflates the number** vs true compounded equity Sharpe (1.29)
- Is NOT comparable across strategies unless they have identical window counts and return distributions
- Masks the fact that some windows are very bad (2021: Sharpe 0.76, 2022: 0.51)

The 5.46 number should NEVER appear on a chart. It should only be used as a relative ranking metric across parameter candidates within the same harness. When comparing to other strategies or reporting to Noah, use the daily equity Sharpe (~1.0-1.3).
