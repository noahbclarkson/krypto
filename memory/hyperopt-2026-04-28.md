# hyperopt-2026-04-28.md — VOL_LOOKBACK Extensive Hyperopt

**Session:** 2026-04-28 UTC | Kira | Hyperparameter optimization
**Target parameter:** `VOL_LOOKBACK`

## Why this parameter
`VOL_LOOKBACK` is a hardcoded ranking-smoothing window in the validated Turtle walk-forward harness. It determines dollar-volume ranking for the top-N portfolio and had only been checked on a sparse subset of values under current params.

## Fixed strategy params
- `CHAND_PERIOD=7`
- `CHAND_MULT=2.30`
- `EP=21`
- `ATR_PERIOD=24`
- `ATR_MULT=2.0`
- `ATR_ENTRY_MULT=0.00`
- `HOLD_MAX=12`
- `POSITION_CAP=3`

## Extensive sweep
- **Range:** `VL = 1..100` (step 1)
- **Validation:** `9 universes × 6 walk-forward windows = 54 OOS windows/value`
- **Selection rule:** robustness-first = pass count > positive universes > avg Sharpe > lower drawdown
- **Harness:** `krypto/examples/vl_extensive_current_params.rs`

## Result
Top robustness ranking:
1. **VL=8** — `40/54` pass, `9/9` positive universes, avg Sharpe `3.1471`, avg return `105.33%`, avg DD `35.41%`, Base5 `6/6`
2. **VL=9** — `40/54` pass, `9/9` positive universes, avg Sharpe `3.1119`, avg return `102.44%`, avg DD `35.81%`, Base5 `6/6`
3. **VL=2** — `39/54` pass, `9/9` positive universes, avg Sharpe `3.1831`, avg return `109.61%`, avg DD `36.69%`, Base5 `5/6`
4. **VL=7** — `38/54` pass, `9/9` positive universes, avg Sharpe `3.2400`, avg return `105.83%`, avg DD `35.39%`, Base5 `5/6`

## Decision
**Update `VOL_LOOKBACK` from `9 → 8`.**

Reason:
- same global pass rate as VL=9 (`40/54`)
- same universe robustness (`9/9` positive universes)
- same Base5 coverage (`6/6`)
- slightly better avg Sharpe (`3.1471` vs `3.1119`)

This is a **small but real** default improvement. More importantly, the sweep shows a stable robustness plateau around `VL=7..9`; the ranking signal is not hypersensitive.
