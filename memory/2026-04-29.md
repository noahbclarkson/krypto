## Equity Bug Assessment

Harness output shows 221.5x (correct final value). The bug:
- `while bar < total` exits before recording the last exit bar's equity
- Forward-fill then fills `equity_curve[total]` (the last bar) with the correct final equity
- But intermediate values near the end may be wrong (1.0 at bar 2086, 221.5x at bar 2087)
- The final equity is correct by coincidence (bar 2087 = total, forward-fill covers it)

**The fix is documented** (T24 in PLAN.md): add one line to record equity before loop exit.
**Not a production blocker** — live bot doesn't use this harness. But it should be fixed.
