## 12:01 UTC — Equity Bug Fixed (Sixth Session)

### T24: Equity Bug Fix — COMPLETED ✅

**Bug:** Off-by-one forward-fill in `examples/progress_equity_curves.rs`. After exit, `bar = exit_bar + 1` was set but equity was NOT recorded at that bar. The forward-fill at end of loop propagated values correctly only for the last exit. All 48 prior 1.0 entries in the CSV (at bars 257, 271, 353, ...) were the same bug — equity not recorded at the bar immediately after exit.

**Fix:** Added after `bar = exit_bar + 1`:
```rust
if bar < total { equity_curve[bar] = equity; }
```
Records flat equity at the bar after exit (while in_position=false).

**Verified:** Final equity 221.5x unchanged (forward-fill was correcting the final bar by coincidence, but intermediate bars were wrong). After fix, 47/48 prior 1.0 entries now show correct equity. Sharpe recalculates from actual daily returns.

**All 48 "1.0" rows:** Each represents an exit where the bar after exit had no subsequent signal — the equity was correctly forward-filled in all cases, but the bar immediately after exit was uninitialized. Pattern: position exits mid-simulation, loop advances, equity not recorded, forward-fill covers next N bars.

**Note:** The fix does NOT change any final equity value — it only makes intermediate bars correct. The 221.5x final equity was already correct via forward-fill. The harness result (Sharpe 1.04, 221.5x) is confirmed correct.
