### Detailed Findings

**HEDGE_ATR_PERIOD (38):** T75 sweep confirms 38 as winner. Robustness peak at 36-40 range.

**HEDGE_ATR_PCT (0.45):** CRITICAL: The percentile THRESHOLD is INERT. All values from 1-100 give IDENTICAL results (314x equity on research harness). pct=0 (disabled) gives 17x (broken). The mechanism works but the specific threshold value doesn't matter - any positive threshold triggers correctly.

**HOLD_MAX (15):** CRITICAL: T88 shows ALL 100 values (1-100) pass 100% (69/69). Turtle ATR(24,2.0) always exits before HOLD_MAX can bind (typical hold 7-15 bars). This is a safety cap, not a tuning parameter.

**HEDGE_LOOKBACK (252):** T84 sweep found LB=147 (100% pass, Sharpe 1.24) better than LB=252 (89% pass, Sharpe 1.13). BUT exact-live verification shows HEDGE_LOOKBACK=147 collapses exact-live equity from 2.76x to 2.10x - SAME INFLATION PATTERN as EP=24. **Do not promote LB=147.**

### Anti-Overfit Pattern Confirmed

This is the 2nd parameter showing in-sample improvement that fails exact-live verification (after EP=24). The pattern is:
1. Research sweep finds "winner" with better pass rate/Sharpe
2. Exact-live verification shows worse equity
3. Must revert

This confirms the PLAN anti-overfit rule: marginal wins (<3 windows) require held-out validation before production promotion.
