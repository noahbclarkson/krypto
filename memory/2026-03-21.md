# Kira Session Log - 2026-03-21

## Session Summary
Investigated and fixed major issues with the paper trading bot's stop loss implementation.

## Key Findings

### Paper Bot vs Backtest Divergence
- **Backtest:** +128% return, 89 trades, 58.4% win rate
- **Paper Bot (before fix):** -25.2% return, 48 trades, 29.2% win rate
- **Paper Bot (after fix):** -11.1% return, 60 trades, 49.1% win rate

### Root Causes Identified

1. **Fixed vs Trailing Stop**
   - Adapter was using FIXED stop (entry_price - atr × mult)
   - Backtest uses TRAILING stop (highest/lowest × (1 ± trailing_sl))
   - Fixed for LONG: stop = highest × (1 - sl)
   - Fixed for SHORT: stop = lowest × (1 + sl)

2. **Warmup Period Impact**
   - Adapter needs 20 bars warmup before generating signals
   - Backtest can trade from bar 1 onwards
   - Paper bot misses early profitable trades (bars 1-20)
   - This explains trade count difference (89 vs 60)

3. **ATR-Based Trailing SL Calculation**
   - Convert ATR×0.30 to percentage: trailing_sl = (atr × 0.30) / entry_price
   - Apply to highest/lowest since entry for trailing effect
