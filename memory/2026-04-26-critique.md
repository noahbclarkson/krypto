## 5. Our Biggest Blind Spots

### BLIND SPOT 1: Failure Mode Opacity (HIGH — NEW THIS SESSION)
We know 13/54 windows fail. We know LTC/EOS/BCH are the primary culprits. But we don't know:
- In how many of those 13 failures is the failure PURELY LTC/EOS/BCH (i.e., BTC/ETH/SOL/DOGE/XRP all pass)?
- In how many does regime matter? (Could BTC fail in the same conditions that cause LTC to fail?)
- What's the worst-case scenario for our production universe (Base5 = BTC/ETH/SOL/XRP/DOGE/ADA)?

**Risk:** MEDIUM-HIGH. If regime is a significant factor, Base5's 100% pass rate is partially survivorship bias from a bull-era sample. A severe chop/bear regime could cause failures we haven't modeled.

**Action:** Run a per-symbol failure analysis — for each of the 13 failing windows, check which symbols pass and which fail. Classify as asset-specific or regime-wide.
